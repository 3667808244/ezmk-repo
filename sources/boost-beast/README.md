# boost-beast

Boost.beast — HTTP/WebSocket library built on Asio

- **Version**: 1.88.0 (Boost release)
- **License**: Boost Software License 1.0
- **Type**: Header-only
- **Source**: [boostorg/beast](https://github.com/boostorg/beast)
- **Dependencies**: boost-config, boost-assert, boost-core, boost-asio, boost-system, boost-smart-ptr

## Usage

Add to your `ezmk.toml`:
```toml
[depends]
lib = ["boost-beast"]
```
