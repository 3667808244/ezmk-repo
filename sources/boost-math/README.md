# boost-math

Boost.math — Mathematical special functions (header-only)

- **Version**: 1.88.0 (Boost release)
- **License**: Boost Software License 1.0
- **Type**: Header-only
- **Source**: [boostorg/math](https://github.com/boostorg/math)
- **Dependencies**: boost-config, boost-assert, boost-core, boost-static-assert, boost-throw-exception

## Usage

Add to your `ezmk.toml`:
```toml
[depends]
lib = ["boost-math"]
```
