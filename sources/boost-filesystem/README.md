# boost-filesystem

Boost.filesystem — Cross-platform filesystem operations (header-only)

- **License**: Boost Software License 1.0
- **Type**: Header-only
- **Source**: [boostorg/filesystem](https://github.com/boostorg/filesystem)

## Usage

Add to your `ezmk.toml`:
```toml
[depends]
lib = ["boost-filesystem"]
```
